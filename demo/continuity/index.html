    What you need for a real move or recovery
    • Keep a recovery key offline and pin the public tree version that lists it before you need it.
    • For a move, copy the post and any pinned versions to the new blyg. Sign a tree there that names the old address, add the former origin to the new manifest, and set a permanent redirect on the old manifest.
    • For a planned rotation, sign with both keys. For emergency recovery, sign with the new key and an offline key listed in the pinned tree. A current tree accepts its current key and at most one previous key.
